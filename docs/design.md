# MosaicMan 設計書

## 1. プロジェクト概要
MosaicMan は、既に公開済みの画像・動画へ後付けでモザイクを適用するためのローカル完結型デスクトップアプリケーションです。クリエイターがクラウドへ素材を送信せずに、顔や身体などの秘匿したい領域へ安全に加工できることを主目的とします。

## 2. アーキテクチャ概要（コンポーネント図的な説明）
- `gui.app`: アプリ全体のワークフロー制御
- `gui.preview`: 画像プレビュー、検出結果の可視化、手動領域追加
- `gui.settings`: モザイク種類と各パラメータ設定
- `core.detector`: OpenCV Haar 分類器による推薦領域検出
- `core.mosaic`: 各種モザイク効果の実処理
- `core.media`: 画像・動画の読み込みと保存、動画書き出し
- `utils.security`: パス検証と出力パスのサニタイズ

GUI 層はユーザー操作を受け取り、コア層へ処理を委譲します。コア層は GUI 非依存にしており、将来的な CLI 化やバッチ処理への再利用を容易にしています。

## 3. モジュール設計（各モジュールの責務）
- `mosaic.py`
  - ピクセル化、ガウシアンぼかし、黒帯描画を統一 API で提供
  - NumPy 配列と PIL Image の両方を扱えるようにする
- `detector.py`
  - 顔検出を実行し、GUI が扱いやすい `DetectedRegion` へ正規化
- `media.py`
  - ファイル形式ごとの I/O を集約
  - 動画処理時は一時ファイルへ書き出して成功時のみ最終配置
- `preview.py`
  - 表示スケールと実画像座標の変換を担当
  - 推薦領域の有効/無効切替、手動追加を提供
- `settings.py`
  - UI 状態を `MosaicConfig` に変換
- `security.py`
  - パストラバーサルや不正拡張子を防止

## 4. データフロー（ファイル読み込み→検出→プレビュー→適用→保存）
1. ユーザーがファイルを選択
2. `media.py` が安全なパス検証後に画像/動画を読み込む
3. `detector.py` が推薦領域を生成
4. `preview.py` が候補を表示し、ユーザーが採用・除外・追加を行う
5. `settings.py` が UI 値を `MosaicConfig` に変換
6. `mosaic.py` が選択領域へエフェクトを適用
7. `media.py` が画像または動画を保存

## 5. セキュリティ設計
- 入力ファイルは拡張子と実在性を検証
- `..` を含むパスを拒否し、シンボリックリンクを解決して扱う
- 出力先はサニタイズし、必要に応じて基準ディレクトリ配下へ制限可能
- クラウド連携を行わず、素材はローカル完結で処理
- 動画保存は `.part` ファイルを介して行い、失敗時の破損を回避
