# MosaicMan ユーザーマニュアル

## 1. インストール方法（uv を使った手順）
1. Python 3.11 以上をインストールします。
2. `uv` を未導入の場合は `pip install uv` を実行します。
3. プロジェクトディレクトリで以下を実行します。
   ```bash
   uv sync --dev
   ```
4. GUI 実行に必要な PySide6 と、動画処理用 FFmpeg バイナリが利用可能か確認してください。

## 2. 起動方法
以下のいずれかで起動します。

```bash
uv run mosaicman
```

または

```bash
uv run python -m mosaicman.main
```

## 3. 基本的な使い方（画像にモザイクをつける手順）
1. 「開く」で画像ファイルを選択します。
2. 「検出」を押して推薦領域を自動抽出します。
3. プレビュー上で不要な領域をクリックして無効化します。
4. 領域が足りない場合はドラッグして手動追加します。
5. 右側の設定パネルでモザイク種類や強さを調整します。
6. 「適用」でプレビュー反映します。
7. 「保存」で出力先を選び、画像を書き出します。

## 4. 動画への適用
1. 「開く」で動画を選択します。
2. 先頭フレームをプレビューに表示します。
3. 「検出」または手動ドラッグで対象領域を設定します。
4. 「適用」で先頭フレームの見た目を確認します。
5. 「保存」で動画全体へ同じ領域設定を適用しながら書き出します。

> 動画保存には時間がかかる場合があります。処理中はアプリを閉じないでください。

## 5. モザイク設定の説明
- **ピクセル化**: ブロックサイズを大きくすると粗いモザイクになります。
- **ぼかし**: 半径を大きくすると強くぼけます。内部では奇数値へ補正されます。
- **黒帯**: 本数、角度、不透明度を調整できます。
- **領域追加**: プレビュー上をドラッグすると独自領域を追加できます。

## 6. よくある質問
### Q. 検出結果が出ません
Haar 分類器は顔向きや解像度に影響されます。手動ドラッグで領域を補ってください。

### Q. PNG で保存する理由は？
画像の無劣化保存を優先するためです。JPEG 保存も可能ですが、再圧縮が発生します。

### Q. 動画で音声は維持されますか？
FFmpeg が利用可能な環境では、可能な限り元動画の音声を引き継ぐよう試行します。

### Q. オフラインで使えますか？
はい。MosaicMan はローカルで完結し、クラウドへ素材を送信しません。
